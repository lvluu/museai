# 90-Day Launch Roadmap

Validate the concept with a controlled experiment. These are production targets, not promises of growth.

## Days 1–7 — Brand and preparation
- [ ] Final channel name and @handle (check availability)
- [ ] Logo and visual identity (`brand/style-guide.md`)
- [ ] Thumbnail template
- [ ] Choose a narrator voice and lock its settings
- [ ] Generate 5 test illustrations to confirm the style is consistent
- [ ] Topic backlog at 50 topics, scored
- [ ] Select videos 001–003
- [ ] Bookmark the YouTube policy pages

## Days 8–30 — Production validation
- [ ] Publish 3–4 long-form videos
- [ ] Publish 6–10 Shorts
- [ ] Test 2–3 storytelling approaches (e.g. myth-bust vs. historical narrative)
- [ ] Settle on a sustainable editing workflow
- [ ] Log production hours per video

## Days 31–60 — Refinement
- [ ] Publish 4 more long-form videos
- [ ] Publish 8–12 Shorts
- [ ] Study retention graphs and note the drop-off points
- [ ] Improve hooks and thumbnails (A/B test with YouTube's "Test & compare")
- [ ] Identify the strongest pillar

## Days 61–90 — Consistency
- [ ] Publish 4 more long-form videos
- [ ] Publish 8–12 Shorts
- [ ] Launch 1–2 recurring series (e.g. "Things We Never Question", "Lost Technologies")
- [ ] Improve production efficiency
- [ ] 90-day analytics review → decide what to double down on

## 90-day targets
| Long-form | Shorts | Researched topics |
|---|---|---|
| 12 | 22–34 | 50+ |

## Weekly rhythm (suggested)
| Day | Task |
|---|---|
| Mon | Research the next video, verify claims |
| Tue | Write the script, run QA prompt 4 on the script |
| Wed | Storyboard and generate illustrations |
| Thu | Narration and edit |
| Fri | Thumbnail, title, QA checklist, schedule |
| Sat | Shorts (2–3) and a community post |
| Sun | Off / review analytics |
