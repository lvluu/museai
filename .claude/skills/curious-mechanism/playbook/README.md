# The Curious Mechanism

> *Nothing is ordinary when you understand how it works.*

A faceless, AI-assisted, illustrated educational YouTube channel. It explains the hidden engineering, design decisions and strange history behind everyday things.

## Channel identity

| | |
|---|---|
| Category | Educational entertainment / mini-documentaries |
| Format | Faceless, AI-assisted (research and editorial judgement stay human) |
| Language | English, global audience |
| Long-form | 8–12 min, 1 per week |
| Shorts | 20–60 s, 2–3 per week |
| Visual identity | Vintage scientific engravings + animated technical diagrams |
| Editorial question | **Why is the world designed and built this way?** |

## How to use this folder

1. Read `PLAYBOOK.md` once, end to end.
2. Set up the brand: `brand/style-guide.md`.
3. Fill `research/topic-backlog.md` up to 50 topics. Score each one with `templates/topic-scorecard.md`.
4. For each video, copy `production/_template-video/` to `production/NNN-slug/`, then work through the pipeline:
   `research.md` → `script.md` → `storyboard.md` → assets → edit → `qa-checklist.md`.
5. Publish with `publishing/`, then log results in `publishing/analytics/metrics-log.md`.
6. Follow `roadmap/90-day-plan.md`.

## The 10 operating rules

1. One video answers one interesting question.
2. Research before writing. Never invent facts.
3. Curiosity comes before technical complexity.
4. Every scene must contribute to the explanation.
5. Visual consistency matters more than visual quantity.
6. Use AI as a production tool, not as a substitute for original thinking.
7. Never publish misleading information or thumbnails.
8. Never use copyrighted assets without appropriate rights.
9. Prioritise viewer retention over unnecessary video length.
10. Improve based on evidence, not assumptions.

**First milestone:** prove you can repeatedly produce an interesting, accurate, visually consistent 8–12 minute documentary. Subscribers come later.
