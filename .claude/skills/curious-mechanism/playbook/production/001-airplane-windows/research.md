# Research — 001 Why Are Airplane Windows Round?

**Central question:** Why do passenger aircraft windows have rounded corners instead of square ones?
**One-sentence answer (to verify):** Sharp corners concentrate stress in a pressurised fuselage. Repeated pressurisation cycles can start fatigue cracks there, so rounded corners spread the load.
**Twist candidate:** The lesson was learned the hard way with the de Havilland Comet, the world's first jet airliner.
