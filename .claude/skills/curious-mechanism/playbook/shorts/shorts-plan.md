# Shorts Plan

Each Short is a complete mini-story: **hook (≤ 2 s) → one curiosity → payoff**. It isn't a trailer. Use 9:16 vertical, 30–55 s, ~75–130 words.

Shorts structure:
1. **0–2 s:** a visual and a spoken question.
2. **2–35 s:** the explanation (2–4 scenes).
3. **35–50 s:** the payoff, ideally with a twist.
4. Optional: "Full story on the channel."
